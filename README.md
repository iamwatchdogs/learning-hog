# Learning-Hog

Learning-hog is a simple, yet powerful tool that gathers multiple learning resources from across the Internet to learn any concept for free of cost. This project targets all possible medium and returns list of resource and generates a roadmap that can help you learn at your own pace.

This project fetches all possible resources from standard sources and then goes further to find the hidden gems that stay hidden due to bad SEO while performing high precision highly relevant topic specific research. And unlike deep research & NotebookLM that summarize everything and makes you lazy to put effort to have deeper understanding, this project put actual resource ahead of the summarization and gives you an suggested guided roadmap for your indepth learning.

This is not a replacement of any of the exsiting solution, but a complete opposite approach towards learning. While the concept of finding resource might still be same, but unlike other tool that make you lazy enough to feel like you learnt everything, this project prioritize for you to take up the responsible to educate yourself but putting in effort to learning the concept by understanding the full context of the actual resource.

Similar all other tools on the same landscape, this project does requires access to an LLM for its premium feature such as deep research, hidden gem miner and personalized roadmap. But you can still use it to gather standard search results any kind of configuration.
